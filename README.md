# Heart Disease Prediction Using Machine Learning

## Project Overview

This project explores the use of machine learning to classify heart disease status based on patient health information. It is being developed as part of a Data Mining Methods course.

The project will include exploratory data analysis, data preprocessing, training and comparison of eight machine-learning methods, and model evaluation.

We also plan to experiment with Principal Component Analysis (PCA), Linear Discriminant Analysis (LDA), and model explainability techniques.

## Dataset

**Dataset:** Heart Failure Prediction Dataset  
**Source:** [Kaggle — fedesoriano](https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction)

The dataset contains 918 records, 11 input features, and one target variable named `HeartDisease`.

The dataset combines older heart disease datasets, so its results should not be assumed to represent current patient populations.
